1 — Ranking general

Cómo se calcula

Para este ranking se toma el producto/servicio y todos los atributos ingresados y el modelo de IA se encarga de hacer el prompt 5 veces. Este prompt consiste en un ranking de productos/servicios en el que según el puesto donde aparezcan estos recibirán puntos 1º=5, 2º=4, 3º=3, 4º=2, 5º=1. Luego se suma por producto/servicio y tomamos cada total a porcentaje sobre 100.
